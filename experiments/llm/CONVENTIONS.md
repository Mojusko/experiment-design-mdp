Keep everything simple (KISS). Less code is better. Rather than supporting cumbersome and wanted functionality, do one thing and do it well.
It is always better to crash with meaningful error, even if uncaught, than to overly-handle many states that shouldn't exist.
Keep things modular and clean. Everything should be based on compoenents with clear and defined goal. 
Don't compromise for hacky solutions, change the infrastrature if needed for better future code management.
This project is shared between multiple contributors. Readbility and documentation is important.
